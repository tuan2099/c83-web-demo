- Mở `index.html` để xem mục lục dẫn tới 14 trang.
- Mỗi trang nằm trong `trang_XX/code.html`.
- Header & footer lấy đồng bộ từ c83group.vn; màu + bố cục đã đồng bộ 1320px.
